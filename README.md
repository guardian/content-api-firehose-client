Content API Firehose Client (now moved into `content-api-scala-client`)
============================

_A client for the Guardian's [Content API](http://explorer.capi.gutools.co.uk/) firehose - an events stream for all updates and deletes of Guardian content_

As of [September 2026](https://github.com/guardian/content-api-scala-client/pull/516),
this project now lives inside the `content-api-scala-client` project, at
[`/firehose-client`](https://github.com/guardian/content-api-scala-client/tree/main/firehose-client).
